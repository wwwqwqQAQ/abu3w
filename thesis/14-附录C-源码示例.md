## C.1 突破买入策略（ABuFactorBuyBreak.py）

这是系统中最简单的买入策略实现——收盘价创 N 日新高时买入。完整展示了买入因子的标准结构：继承基类、混入方向、实现 fit_day 方法。

```python
# -*- encoding:utf-8 -*-
"""
    买入择时示例因子：突破买入择时因子
"""

from __future__ import absolute_import
from __future__ import print_function
from __future__ import division

from .ABuFactorBuyBase import AbuFactorBuyBase, AbuFactorBuyXD, BuyCallMixin, BuyPutMixin

__author__ = '阿布'
__weixin__ = 'abu_quant'


class AbuFactorBuyBreak(AbuFactorBuyBase, BuyCallMixin):
    """示例正向突破买入择时类，混入BuyCallMixin，即向上突破触发买入event"""

    def _init_self(self, **kwargs):
        """kwargs中必须包含: 突破参数xd 比如20，30，40天...突破"""
        self.xd = kwargs['xd']
        self.factor_name = '{}:{}'.format(self.__class__.__name__, self.xd)

    def fit_day(self, today):
        """
        针对每一个交易日拟合买入交易策略，寻找向上突破买入机会
        :param today: 当前驱动的交易日金融时间序列数据
        """
        # 忽略不符合买入的天（统计周期内前xd天）
        if self.today_ind < self.xd - 1:
            return None

        # 今天的收盘价格达到xd天内最高价格则符合买入条件
        if today.close == self.kl_pd.close[self.today_ind - self.xd + 1:self.today_ind + 1].max():
            self.skip_days = self.xd
            # 信号基于今日收盘价，所以明天买
            return self.buy_tomorrow()
        return None


class AbuFactorBuyXDBK(AbuFactorBuyXD, BuyCallMixin):
    """继承AbuFactorBuyXD完成正向突破买入，代码更简洁"""
    def fit_day(self, today):
        if today.close == self.xd_kl.close.max():
            return self.buy_tomorrow()
        return None


class AbuFactorBuyPutBreak(AbuFactorBuyBase, BuyPutMixin):
    """反向突破买入（做空），混入BuyPutMixin"""

    def _init_self(self, **kwargs):
        self.xd = kwargs['xd']
        self.factor_name = '{}:{}'.format(self.__class__.__name__, self.xd)

    def fit_day(self, today):
        if self.today_ind < self.xd - 1:
            return None
        # 向下突破：收盘价创xd日新低
        if today.close == self.kl_pd.close[self.today_ind - self.xd + 1:self.today_ind + 1].min():
            self.skip_days = self.xd
            return self.buy_tomorrow()
        return None
```

**代码要点解读：**

- `AbuFactorBuyBase` 是买入因子基类，`BuyCallMixin` 声明做多方向
- `_init_self` 在因子初始化时调用，接收策略参数（如 `xd=60` 表示 60 日突破）
- `fit_day` 是核心——回测引擎每个交易日调用一次，返回订单或 None
- `self.today_ind` 是当前交易日在 K 线序列中的索引
- `buy_tomorrow()` 表示信号基于当日收盘价判断、次日开盘执行，避免前向偏差
- `skip_days = xd` 表示信号触发后冷却 xd 天，避免同一突破位反复入场

## C.2 回测入口函数（ABu.py 核心片段）

run_loop_back 是系统的总入口——传入资金、策略因子和股票池，返回完整回测结果。

```python
def run_loop_back(read_cash, buy_factors, sell_factors, stock_picks=None,
                  choice_symbols=None, n_folds=2, start=None, end=None,
                  commission_dict=None, n_process_kl=None, n_process_pick=None):
    """
    封装执行择时，选股回测。

    :param read_cash: 初始化资金额度，eg：1000000
    :param buy_factors: 买入因子策略序列
    :param sell_factors: 卖出因子策略序列
    :param stock_picks: 选股因子序列
    :param choice_symbols: 备选股票池，None则全市场回测
    :param n_folds: 回测n_folds年的历史数据
    :param start/end: 回测起止日期
    :param commission_dict: 自定义手续费
    :return: (AbuResultTuple对象, AbuKLManager对象)
    """
    # 1. 创建基准时间轴
    benchmark = AbuBenchmark(n_folds=n_folds, start=start, end=end)

    # 2. 初始化虚拟资金账户
    capital = AbuCapital(read_cash, benchmark, user_commission_dict=commission_dict)

    # 3. 多进程并行选股
    choice_symbols = AbuPickStockMaster.do_pick_stock_with_process(
        capital, benchmark, stock_picks, choice_symbols=choice_symbols,
        n_process_pick_stock=n_process_pick)

    if choice_symbols is None or len(choice_symbols) == 0:
        return None, None

    # 4. 批量获取K线数据
    kl_pd_manager = AbuKLManager(benchmark, capital)
    kl_pd_manager.batch_get_pick_time_kl_pd(choice_symbols, n_process=n_process_kl)

    # 5. 多进程并行择时回测
    orders_pd, action_pd, _ = AbuPickTimeMaster.do_symbols_with_same_factors_process(
        choice_symbols, benchmark, buy_factors, sell_factors,
        capital, kl_pd_manager=kl_pd_manager, n_process_pick_time=n_process_pick)

    # 6. 打包返回结果
    abu_result = AbuResultTuple(orders_pd, action_pd, capital, benchmark)
    return abu_result, kl_pd_manager
```

**执行流程：** 基准时间轴 → 资金账户 → 并行选股 → 拉取 K 线 → 并行回测 → 结果打包。六步走完一次完整回测。
