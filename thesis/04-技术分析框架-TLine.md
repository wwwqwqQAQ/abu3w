# 第四章 技术分析框架：TLineBu系统

## 4.1 TLineBu设计哲学

TLineBu（技术线业务单元）是阿布量化系统中最具理论深度的模块。它的核心设计哲学是"万物皆为技术线"——任何金融时间序列都可以被抽象为一个AbuTLine对象，然后通过一套统一的数学工具进行分析。这套工具包括：
- 统计特征提取
- 回归趋势分析
- 骨架通道构建
- 支撑/阻力位识别
- 位移-路程比计算
- 黄金分割和比例分割分析。

AbuTLine类是这一设计哲学的具体实现。它接收一个数值序列（line）和一个名称（line_name），在初始化时自动计算七个统计特征：

- mean：序列的算术平均值
- std：序列的标准差
- high：均值 + 一倍标准差
- low：均值 - 一倍标准差
- close：序列的最后一个元素
- score：(close - low) / (high - low)，一个范围在[0, 1]的归一化位置指标，量化了当前值在历史统计范围内的相对位置

这些统计特征为所有后续分析提供了统一的参考框架。high和low构成了基于标准差的动态通道，close的score值则是一个简洁的趋势强度度量。

## 4.2 缩放变换

在做位移-路程分析时，水平轴是日期，垂直轴是价格——两个维度的单位完全不同。如果不做缩放转换，位移（两点间的直线距离）和路程（价格走过的总路径）就无法在同一个坐标系里比较。y_zoom的作用就是把价格按时间轴的比例缩放，确保两个维度在数值上是可比的。其核心公式为：

```
y_zoom = (x.max() / tl.max()) * tl
```

(公式4-1)

这个看似简单的操作在实际分析中意义重大。在位移-路程分析中，水平距离（时间维度）和垂直距离（价格维度）的单位不同——一个是交易日数量，一个是价格单位。如果不进行等比例缩放，位移-路程比将失去几何意义。y_zoom确保了位移-路程比计算的尺度一致性。

## 4.3 趋势方向判断

判断一只股票当前是上升趋势还是下降趋势——这听起来简单，但要做成自动化的数学判断并不容易。肉眼一看就知道"在涨"，但程序需要量化标准。系统的方法是：对价格序列做一次多项式（直线）拟合，看拟合线的倾斜角度。角度够大、拟合质量够好，才认为确实有趋势。这比简单的"最近涨了就是上升趋势"要严谨得多。

### 4.3.1 基于多项式拟合的趋势识别

is_up_trend和is_down_trend方法使用一次多项式（线性）拟合来判断序列的基本趋势方向。算法流程如下：

1. 使用ABuRegUtil.valid_poly测试序列是否可以用一次多项式充分描述。valid_poly内部对序列进行最小二乘线性拟合，使用R²（决定系数）作为拟合优度度量。

2. 如果拟合通过验证，计算拟合线的斜率角度（度数）：

```
angle = arctan(slope * (x.max() - x.min()) / (y.max() - y.min())) * 180 / π
```

(公式4-2)

需要注意的是，这里的斜率不是在原始数值空间计算的，而是在经过等比例缩放的标准坐标空间中计算的，以确保物理意义。

3. 角度阈值判断：angle >= 5度时为上升趋势（is_up_trend = True），angle <= -5度时为下降趋势（is_down_trend = True）。

这个5度阈值是经过实证调优的参数——角度太小意味着趋势不够显著，可能只是随机游走；而5度的门槛能够有效过滤掉无趋势的震荡行情。

### 4.3.2 多项式拟合验证

ABuRegUtil.search_best_poly函数使用迭代搜索策略寻找最优的多项式拟合次数。搜索从高次（默认7次）开始，在1至100的范围内搜索，目标是最小化拟合残差的同时避免过拟合。poly_valid函数使用交叉验证或多重假设检验来确认拟合的统计显著性。

## 4.4 骨架通道

骨架通道（Skeleton Channel）是TLineBu提供的一种创新的降噪方法。其核心思想是将长序列按时间步长（step_x）分片，在每个片段内提取代表点（骨架点），然后将骨架点连接成简化线。与移动平均线相比，骨架通道能够保留价格运动的关键结构（如极值点和转折点），而非简单的平滑。

### 4.4.1 骨架类型

系统提供了六种骨架点的计算方式：

- skeleton_min：每个片段的最小值，构成序列的下边界
- skeleton_max：每个片段的最大值，构成序列的上边界
- skeleton_mean：每个片段的平均值，构成序列的中轴线
- skeleton_median：每个片段的中位数，对异常值不敏感
- skeleton_close：每个片段的最后一个值，保留时间方向的最终信息
- skeleton_triangle：每个片段中的最大值和最小值，第三点由极值出现的位置决定（起点或终点）。这种三角形骨架能够在简化表示中保留价格运动的三角形形态（上升三角形、下降三角形、对称三角形）

### 4.4.2 骨架通道的应用

show_skeleton_channel方法同时绘制上骨架线（skeleton_max）和下骨架线（skeleton_min），两条线之间的区域构成价格运动的"通道"。通道的宽度反映了价格的波动范围：通道越窄，价格运行越紧凑（收敛）；通道越宽，价格波动越剧烈（发散）。

当价格突破上骨架线时，可能意味着突破性上涨；当价格跌破下骨架线时，可能意味着趋势反转。而当价格在通道内运行时，上下骨架线分别充当动态阻力位和支撑位。

## 4.5 BFGS骨架优化

show_skeleton_bfgs方法使用数值优化技术精确定位骨架的关键点。其算法流程为：

1. 使用scipy.interpolate.interp1d构建序列的插值模型。interp1d在两个已知数据点之间进行线性或样条插值，使得可以评估任意x位置的序列值。

2. 在每个时间片段内，将原始序列点作为初始猜测（initial guess），使用scipy.optimize.fmin_bfgs（Broyden-Fletcher-Goldfarb-Shanno拟牛顿法）在该片段内搜索局部极小值。

3. BFGS算法是一种迭代的、基于梯度的优化算法。假设目标函数f(x)在局部可以用二次函数近似：

```
f(x_k + p) ≈ f(x_k) + ∇f(x_k)^T p + (1/2) p^T B_k p
```

其中B_k是Hessian矩阵的近似。BFGS通过更新公式迭代地改进B_k：

```
B_{k+1} = B_k + (y_k y_k^T) / (y_k^T s_k) - (B_k s_k s_k^T B_k) / (s_k^T B_k s_k)
```

(公式4-3)

其中s_k = x_{k+1} - x_k，y_k = ∇f(x_{k+1}) - ∇f(x_k)。

4. 找到的局部极小值即构成骨架的关键点——这些点代表了价格运动的局部支撑位或趋势拐点。

与传统基于规则的方法（如N日最低价）相比，BFGS方法能够更精确地定位极值点，尤其是当极值出现在两个交易日之间时（例如由于非交易日或停牌导致的数据缺失）。

## 4.6 位移-路程比

位移-路程比（Shift-Distance Ratio，SD Ratio）是TLineBu中最具原创性的分析工具之一。它从物理学中的"路程/位移"概念出发，量化金融时间序列的"弯曲程度"。

将一段价格序列视为从起点A到终点B的路径。定义：

- h_distance（水平距离）= 索引差（时间步数）
- v_distance（垂直距离）= |价格终点 - 价格起点|（价格变化的绝对值）
- distance（斜边）= √(h² + v²)，即从起点到终点的直线距离（位移量）
- shift（路程）= Σ|p_i - p_{i-1}|，即价格在路径上走过的总路程（每个连续点之间绝对差值的累加）
- sd（位移-路程比）= shift / distance

### 4.6.2 几何解释

位移-路程比的最小值为1（当价格沿直线运动时，路程等于位移）。比值越大，说明价格运动的"弯曲度"越高——价格在达到终点的过程中走过了大量冗余的路程。在趋势行情中，sd接近1，意味着价格运行效率高、趋势清晰；在震荡行情中，sd远大于1，意味着价格反复波动、方向不明确。

这一指标从几何角度捕捉了市场效率——一个高效率的市场（EMH假设下的理想状态）应该呈现随机游走，sd值较高；而一个有明确趋势的市场则呈现方向性运动，sd值较低。因此，sd指标实际上是一个趋势质量或市场效率的度量。

### 4.6.3 终点计算方式

系统提供了三种终点计算方式：

- shift_distance_close：使用序列的最后一个值作为终点。适用于一般的趋势分析。
- shift_distance_maxmin：在上升趋势中使用最大值作为终点，在下降趋势中使用最小值作为终点。这样计算出的sd更能反映"趋势过程中的弯曲程度"，而非最终结果的弯曲程度。
- shift_distance_sum_maxmin：综合使用极值终点，提供更全面的趋势质量评估。

## 4.7 趋势速度/敏感度

calc_kl_speed函数提供了一种量化的趋势稳定性度量。算法如下：

1. 将价格序列按resample天数进行重采样，例如将日线转换为周线（resample=5）或月线（resample=22）。

2. 计算每期重采样价格的差值（diff），然后二值化为+1（差值>0，即本期上涨）和-1（差值≤0，即本期下跌）。这构成了一条"慢速趋势线"。

3. 将慢速趋势线向前平移一期，得到"快速趋势线"。

4. 计算kl_trend_ffs = fast * slow（逐元素乘积）：

   - 乘积为+1：快速趋势和慢速趋势方向一致，意味着趋势在持续
   - 乘积为-1：方向不一致，意味着趋势发生了反转

5. 趋势速度 = 方向一致的期数 / 总期数。

这一指标直观地衡量了趋势的"持续性"。趋势速度接近100%意味着价格沿同一方向持续运动（强趋势），趋势速度接近50%意味着方向频繁变化（震荡/无趋势），趋势速度接近0%意味着趋势方向每次都在反转（极端的均值回归）。

## 4.8 回归趋势通道

regress_trend_channel函数基于普通最小二乘法（OLS）构建动态的支持/阻力通道。其算法有别于传统的布林带：

1. 对序列进行线性回归：y_fit = a + b * x（a为截距，b为斜率）。

2. 计算每个序列点到拟合线的垂直距离：e_i = y_i - (a + b * x_i)。

3. 找到距离最小的点（argmin(e_i)）——即价格在该趋势中最"低于回归线"的位置。将拟合线向下平移该差值，得到下通道线（趋势支撑线）：y_lower = a + b * x - min(e_i)。

4. 找到距离最大的点（argmax(e_i)）——即价格在该趋势中最"高于回归线"的位置。将拟合线向上平移该差值，得到上通道线（趋势阻力线）：y_upper = a + b * x - max(e_i)。

与布林带不同（布林带的标准差带是等宽的），回归趋势通道的宽度由历史极值决定，因此能更好地适应实际价格的波动范围，同时通道线随趋势斜率倾斜。

## 4.9 支撑位与阻力位

### 4.9.1 切比雪夫多项式拟合

support_resistance_pos函数的算法是TLineBu中最为复杂的之一。其核心是使用高次切比雪夫多项式（Chebyshev Polynomial）作为"柔性标尺"来检测价格序列中的凹凸点。

算法流程：

1. 对序列进行去均值处理（通过ABuStatsUtil.demean函数减去均值），去均值后序列在零附近波动。

2. 对于阻力位检测：将去均值后的序列乘以-1（即上下翻转），使得原本的局部最大值变成局部最小值，统一了后续的极值搜索方向。对于支撑位检测：保留原样的去均值序列。

3. 使用ABuRegUtil.search_best_poly搜索最优的多项式拟合次数。搜索策略是从7次开始，在1至100的范围内使用一组预设的候选次数（1, 3, 5, 7, 14, 21, 28, 36, 42, 54, 63, 72, 81, 90, 99）。

4. 将多项式次数放大g_upport_resistance_unit倍（默认为3倍）：构建一个高次切比雪夫多项式拟合模型。切比雪夫多项式由其递推定义：T_0(x) = 1，T_1(x) = x，T_{n+1}(x) = 2x·T_n(x) - T_{n-1}(x)。高次切比雪夫多项式具有在[-1, 1]区间内等振幅振荡的特性，非常适合用于检测价格序列中的周期性凹凸。

5. 对于序列的每一个点，使用scipy.optimize.fmin_bfgs通过切比雪夫多项式模型寻找局部极值。fmin_bfgs在目标函数（切比雪夫多项式值）上沿着梯度下降（上升）的方向搜索，收敛到局部最小值（最大值）。这些局部极值点即为潜在的支撑位/阻力位。

### 4.9.2 K-Means聚类筛选

检测到的支撑位/阻力位通常数量较多且分散在多个价格水平。select_k_support_resistance函数使用K-Means聚类将它们分为几个显著的水平。算法使用肘部法则（Elbow Method）选择最优聚类数k：

1. 对k=1到10的每个值，运行K-Means聚类。

2. 计算每个聚类方案的类内平方和（inertia/within-cluster sum of squares）。

3. 使用0.06的方差解释阈值：当增加一个聚类数带来的方差解释提升小于6%时，停止增加聚类数。这个阈值控制了聚类的粒度——阈值越小，聚类数越多，检测到的支撑/阻力水平越精细。

4. 对于选定的k值，计算每个聚类的质心，质心的y值即为支撑位/阻力位水平。

### 4.9.3 支撑/阻力趋势预测

support_resistance_predict函数在检测到的支撑/阻力位之间构建趋势预测：

1. 将识别出的支撑位点（或阻力位点）按时间排序。

2. 在相邻的支撑位点之间进行线性回归（最小二乘拟合），构建连接线段。

3. 将线段向外延伸（外推），形成持续的趋势支撑线或趋势阻力线。

4. 价格接近预测的支撑线时发出买入信号，接近预测的阻力线时发出卖出信号。

这一过程模拟了技术分析师手工绘制的趋势线，但使用数学方法实现了自动化和系统化的趋势线识别。

## 4.10 黄金分割与比例分割

### 4.10.1 视觉法黄金分割

find_golden_point函数实现了基于价格范围的黄金分割：

```
sp382 = (max - min) * 0.382 + min

sp618 = (max - min) * 0.618 + max  # 注意：618从max方向计算

sp50 = (max - min) * 0.5 + min
```

(公式4-4)

0.382和0.618是斐波那契数列相邻项比值（如34/89 ≈ 0.382，55/89 ≈ 0.618）的极限值。在技术分析中，0.382和0.618被认为是最重要的回调/反弹目标位。50%（即0.5）虽然不是斐波那契数，但作为心理关口也被广泛应用。

### 4.10.2 统计法黄金分割

find_golden_point_ex函数使用分布百分位数而非价格极值：

```
gex_382 = scipy.stats.scoreatpercentile(序列, 38.2)

gex_500 = scipy.stats.scoreatpercentile(序列, 50)

gex_618 = scipy.stats.scoreatpercentile(序列, 61.8)
```

(公式4-5)

视觉法基于极值（受异常值影响大），统计法基于分布（更稳健）。系统同时计算两种方法的黄金分割点，当两组值相近时说明分割点可信度高；当两组值差异大时说明价格分布不均匀，需要谨慎使用。

### 4.10.3 比例分割

find_percent_point函数支持任意百分比的分割。对于一组给定的百分比（例如[20, 30, 40, 60, 70, 80, 90, 95]），函数返回每个百分比的(scoreatpercentile数值, 基于范围的计算)作为上下区间。这为用户提供了比传统斐波那契水平更灵活的价格目标设定方式。

## 4.11 各技术线的具体应用

### 4.11.1 黄金分割应用（ABuTLGolden）

ABuTLGolden将黄金分割的概念应用于实际交易。它不仅计算0.382、0.5、0.618三个基本水平，还引入了"区间"（带状区域）的概念：

- below618 = min(视觉法618, 统计法618)
- above618 = max(视觉法618, 统计法618)

区间越宽，说明该水平的定位越不确定——这为交易者提供了关于该水平可靠性的额外信息。

此外，ABuTLGolden还计算了更多的比例分割点：20%、25%、30%（下方/看跌水平）和70%、80%、90%、95%（上方/看涨水平）。这些水平构成了一个完整的"黄金分割梯子"，为趋势跟踪策略提供了多层目标位。

### 4.11.2 VWAP计算（ABuTLVwap）

ABuTLVwap实现了日线级别的成交量加权平均价格（VWAP）估算：

```
VWAP = Σ(volume_i * price_i) / Σ(volume_i)
```

(公式4-6)

其中price_i可以通过四种方式确定：OHLC_MEAN（开盘/最高/最低/收盘四价的算术平均）、OHLC_MEDIAN、HL_MEAN（最高/最低均值）或直接使用收盘价CLOSE。

需要指出的是，这是对VWAP的日线级别近似。机构级VWAP算法是在日内逐笔计算成交均价，阿布量化系统受限于日线数据的粒度，采用整个K线周期的总成交金额除以总成交量来近似。尽管是近似，这个指标在趋势判断中仍然有效——当价格运行在VWAP之上时，反映了整体的买盘优势；反之则反映了卖盘优势。

### 4.11.3 波动率分析（ABuTLWave）

ABuTLWave实现了多维度的波动率分析：

1. 波动率标准差（calc_wave_std）：计算对数收益率的移动标准差。公式为：
```
return_t = ln(close_t / close_{t-1})

wave_std = rolling_std(return, window=N) * √(N)
```

(公式4-7)
乘以√N是将日波动率年化（根据平方根法则）。这一指标就是经典的已实现波动率（Realized Volatility）。

2. 绝对波动（calc_wave_abs）：使用|p_change|（绝对涨跌幅）按21天（约一个月）重采样求和，形成"月振幅"。然后进行去均值处理，得到围绕零波动的波动序列。

3. 加权绝对波动（calc_wave_weight_abs）：在去均值的基础上进行二次放大：
```
squared_wave = demean² * sign(demean)
```

(公式4-8)
平方操作放大了大波动（市场恐慌或狂热），同时保留了方向符号。对结果应用指数加权移动平均（EWM），使指标对近期波动率变化更加敏感。

### 4.11.4 跳空缺口检测（ABuTLJump）

ABuTLJump实现了系统化的跳空缺口检测，使用三层筛选机制：

1. 第一层（日振幅筛选）：当日振幅（high - low）必须大于前N日的平均日振幅。这确保只有振幅异常放大的日子才被考虑。

2. 第二层（成交量筛选）：当日成交量必须大于前一个月（约22个交易日）的平均成交量。结合第一层筛选，这两层确保了检测到的跳空伴随着交易活跃度的大幅提升。

3. 第三层（跳空阈值）：跳空幅度必须超过月度振幅的jump_diff_factor倍（默认值通过ABuTLExecute.calc_kl_speed的趋势速度指标动态调整）。跳空方向的确定：

   - 向上跳空（代码值+1）：p_change > 0 且 (low - pre_close) > jump_diff
   - 向下跳空（代码值-1）：p_change < 0 且 (pre_close - high) > jump_diff

跳空力量（jump_power）衡量了跳空幅度相对于阈值的大小：
```
jump_power = (low - pre_close) / jump_diff  （向上跳空）
```

(公式4-9)

时间加权（calc_jump_line_weight）通过np.linspace(0, 1, N)创建线性时间权重，最近的跳空被赋予更高的权重（权重*跳空力量），使近期跳空对信号的影响大于远期跳空。

### 4.11.5 ATR标准差线（ABuTLAtr）

ABuTLAtr创造性地计算了"波动率的波动率"：

```
atr_change_t = ln(atr21_t / atr21_{t-1})  （ATR的对数变化率）

atr_volatility = rolling_std(atr_change, window=N) * √(N)  （ATR变化率的波动率）
```

(公式4-10)

这一指标捕捉的是波动率聚类（Volatility Clustering）效应——金融时间序列的一个重要特征是波动率的持续性：高波动率之后往往跟随高波动率，低波动率之后往往跟随低波动率。ATR标准差线的飙升标志着波动率制度转换（Regime Shift），即市场正在从低波动状态转变为高波动状态（或反过来），这对于风险管理和策略调整具有重要意义。

### 4.11.6 相似性技术线（ABuTLSimilar）

ABuTLSimilar将相关性分析的结果转化为可交易的信号。其核心是差异投票机制（regular_diff）：

1. 从全市场相关性筛选中选出与目标标的最高度相关的候选标的。

2. 对候选标的进行协整检验（Engle-Granger协整检验），p值阈值为0.38。

3. 对每个协整的标的：计算其价格与目标标的价格的标准化差异（Z-score差异）。

4. 汇总所有协整标的的差异，形成"投票指标"。

5. 当投票指标超出其统计范围（均值±1倍标准差）时，触发交易信号——定价偏差过大，预期均值回归。

差异投票机制的核心创新在于：它不是简单地比较两只股票，而是综合了多个"最相似"股票的信息，形成了一个稳健的定价偏差度量。
