# 第五章 技术指标系统：IndicatorBu

## 5.1 指标计算架构

IndicatorBu是阿布量化系统的技术指标计算模块，实现了股票技术分析中最常用的八类技术指标。模块的设计遵循统一的计算类型管理策略：通过全局变量g_calc_type控制指标的计算方式——E_FROM_TA表示优先使用TA-Lib（技术分析库），E_FROM_PD表示使用Pandas/NumPy自主实现。系统默认设置为E_FROM_PD，即完全使用自主实现的算法，不依赖外部TA-Lib库。这一设计决策有双重好处：消除了外部依赖（TA-Lib的安装和编译在不同平台上可能存在问题），同时使得所有指标的计算细节可控可调，便于研究和教学。

ABuNDBase基类提供了指标模块的通用功能。plot_from_order函数连接了指标计算和交易可视化：它接收交易订单数据，围绕买卖日期创建向前/向后各扩展date_ext天的分析窗口，获取对应的价格数据，调用指标绘图函数并标注买卖点。

## 5.2 移动平均线系统（ABuNDMa）

移动平均线（Moving Average）是最古老也是最基础的技术分析工具。其核心思想是通过对价格序列进行平滑处理，消除短期随机波动，揭示价格的长期趋势方向。

### 5.2.1 简单移动平均线（SMA）

简单移动平均线赋予过去N天的价格等权重：

```
SMA_t = (P_t + P_{t-1} + ... + P_{t-N+1}) / N
```

(公式5-1)

在Pandas中通过rolling_mean(window=N)实现。系统默认计算30日、60日和90日三条移动平均线，分别对应短期、中期和长期趋势。

SMA的计算复杂度为O(n)——通过维护滑动窗口的和，可以在添加新元素和移除旧元素时O(1)更新（而非每次重新计算N个元素的和）。Pandas的内部实现使用了这一优化。

### 5.2.2 指数移动平均线（EMA）

指数移动平均线赋予近期价格更高的权重，权重随时间按指数衰减：

平滑因子α = 2 / (N + 1)

```
EMA_t = α * P_t + (1 - α) * EMA_{t-1}
```

(公式5-2)

展开形式：
```
EMA_t = α * [P_t + (1-α)P_{t-1} + (1-α)²P_{t-2} + ...]
```

(公式5-3)

权重序列的和趋近于1（无限等比数列求和为α / (1-(1-α)) = 1），确保了EMA是价格的加权平均。N=20时，α≈0.095，最近20天的累计权重约占总权重的86%；N=60时，α≈0.033，最近60天约占87%。

在Pandas中通过ewm_mean(span=N)实现。EMA比SMA更"灵敏"——它对近期的价格变化反应更快，因此更适合用于生成交易信号。

### 5.2.3 葛兰碧八大法则

ABuNDMa集成了基于移动平均线的经典交易信号——葛兰碧八大买卖法则（Granville's Eight Rules）。这八大法则系统化地描述了价格与移动平均线之间的八种交互模式：

**四大买入法则：**

- 买入法则一：均线从持续下跌走平并转为上涨，价格从下方突破均线。这意味着趋势从下跌转为上涨，价格确认了趋势转变。
- 买入法则二：价格在均线上方运行，回撤至均线附近但未跌破均线，随后再度上涨。这意味着上升趋势中的回调结束，上涨趋势延续。
- 买入法则三：价格短暂跌破正在上行的均线，随后迅速回升至均线上方。这是一种"假跌破"，均线仍在上行说明上升趋势未变。
- 买入法则四：价格大幅下跌至均线下方，远离均线。这是一种极端的超卖状态，预期价格将向均线回归。

**四大卖出法则：**

- 卖出法则五：均线从持续上涨走平并转为下跌，价格从上方跌破均线。对应买入法则一的反向。
- 卖出法则六：价格在均线下方运行，反弹至均线附近但未突破均线，随后再度下跌。对应买入法则二的反向。
- 卖出法则七：价格短暂突破正在下行的均线，随后迅速回落至均线下方。一种"假突破"，对应买入法则三的反向。
- 卖出法则八：价格大幅上涨至均线上方，远离均线。一种极端的超买状态，预期价格将向均线回归。

葛兰碧八大法则构成了一套完整的趋势跟踪+均值回复的混合策略框架。

## 5.3 MACD指标（ABuNDMacd）

MACD（Moving Average Convergence Divergence，指数平滑异同移动平均线）是由Gerald Appel在1979年提出的。它将趋势跟踪和动量分析融为一体，是使用最广泛的技术指标之一。

### 5.3.1 数学定义

MACD由三条线构成：

- 快速EMA（DIF基础EMA）：EMA_fast = EMA(close, span=12)
- 慢速EMA（DIF基础EMA）：EMA_slow = EMA(close, span=26)
- DIF线（差离值）：DIF = EMA_fast - EMA_slow
- DEA线（信号线）：DEA = EMA(DIF, span=9)
- MACD柱状线：BAR = DIF - DEA

当BAR为正值（DIF在DEA之上）时，柱状线在零轴上方；当BAR为负值时，柱状线在零轴下方。

### 5.3.2 DIF的数学意义

DIF = EMA(12) - EMA(26)。可以证明，DIF本质上是一个带通滤波器——它对约12-26个交易日的价格变化频率最为敏感，同时过滤掉了高频噪声（日间随机波动）和低频成分（长期趋势）。

EMA(12)对价格变化的响应速度大约是EMA(26)的两倍。当价格开始上涨时，EMA(12)首先抬头，而EMA(26)反应较慢，DIF由负转正（或由小变大）。当价格上涨加速时，DIF的斜率增大；当价格上涨减速时，DIF的斜率减小。因此，DIF同时包含了趋势方向（符号）和趋势动量（斜率）的信息。

### 5.3.3 交易信号

ABuNDMacd识别以下信号模式：

- 金叉（Golden Cross）：DIF从下方向上穿越DEA。发生在零轴上方为强势金叉（趋势行情中的回调结束），发生在零轴下方为反弹金叉（下跌趋势中的反弹）。

- 死叉（Death Cross）：DIF从上方向下穿越DEA。发生在零轴下方为强势死叉，发生在零轴上方为回调死叉。

- 顶背离（Bearish Divergence）：价格创新高而DIF未能创出新高，甚至走低。这意味着上升动能在衰减，尽管价格还在涨，但"内在力量"已经不足。数学上，价格创新高而EMA(12)-EMA(26)减少，意味着短期趋势相对于中期趋势在走弱。

- 底背离（Bullish Divergence）：价格创新低而DIF未能创出新低，甚至走高。这意味着下跌动能在衰竭。数学上，价格创新低而EMA(12)-EMA(26)增加（负值减小），意味着短期趋势相对于中期趋势在走强。

- 零轴穿越：DIF穿越零轴，意味着EMA(12)与EMA(26)的相对位置发生根本性改变——从短期均线在长期均线之下变为之上（或反之），标志着趋势可能发生重大转折。

## 5.4 RSI指标（ABuNDRsi）

RSI（Relative Strength Index，相对强弱指标）由J. Welles Wilder在1978年提出，是最广泛使用的动量振荡指标。

### 5.4.1 数学定义

计算N日价格变化：
```
diff = 价格变化 （默认使用pct_change收益率，由g_rsi_gain控制）
```

(公式5-4)

分离上涨和下跌：
```
gain = max(diff, 0)     # 仅保留上涨部分

loss = abs(min(diff, 0)) # 仅保留下跌部分的绝对值
```

(公式5-5)

N期平滑：
```
avg_gain = rolling_mean(gain, window=N)  （初始值使用SMA，后续使用平滑公式）

avg_loss = rolling_mean(loss, window=N)
```

(公式5-6)

相对强弱比：
```
RS = avg_gain / avg_loss
```

(公式5-7)

RSI值：
```
RSI = 100 - 100 / (1 + RS) = 100 * RS / (1 + RS)
```

(公式5-8)

默认N=14。

### 5.4.2 数学性质

RSI的取值范围为[0, 100]。当avg_gain远大于avg_loss时，RS很大，RSI趋近于100（强势上涨）。当avg_loss远大于avg_gain时，RS很小，RSI趋近于0（强势下跌）。当avg_gain = avg_loss时，RS=1，RSI=50（多空平衡）。

RSI=70意味着avg_gain/avg_loss = 7/3 ≈ 2.33，即上涨幅度约为下跌幅度的2.33倍。RSI=30意味着avg_gain/avg_loss = 3/7 ≈ 0.43。

Wilder提出的原始公式使用了平滑移动平均（Smoothed Moving Average, SMMA），而阿布量化系统的Pandas实现使用的是普通滚动平均。SMMA给予近期数据更高的权重（通过alpha=1/N的指数平滑），这在数学上有所不同，但实际效果差异较小。

## 5.5 布林带（ABuNDBoll）

布林带（Bollinger Bands）由John Bollinger在1980年代提出，是最著名的基于波动率的交易工具。

### 5.5.1 数学定义

中轨 = SMA(N)，默认N=20

带宽 = N期滚动标准差（默认window=20）

上轨 = 中轨 + nb_dev * 带宽（默认nb_dev=2）

下轨 = 中轨 - nb_dev * 带宽

宽度 = 上轨 - 下轨 = 2 * nb_dev * 滚动标准差

### 5.5.2 统计解释

如果价格服从正态分布，±2个标准差应包含约95.4%的价格观测值。然而，金融收益率分布通常呈现尖峰厚尾（leptokurtic fat-tailed）特征，因此实际价格突破布林带的频率高于正态分布假设下的4.6%。

百分比B指标（%B）量化了价格在布林带内的相对位置：
```
%B = (price - lower) / (upper - lower)
```

(公式5-9)
%B=0表示价格在下轨，%B=0.5表示价格在中轨，%B=1表示价格在上轨。

### 5.5.3 交易信号

- 挤压信号（Squeeze）：带宽收窄到历史低位意味着波动率正在收缩，这往往是剧烈行情的"暴风雨前的宁静"。成交量萎缩和窄幅震荡后，市场通常会选择一个方向爆发。

- 突破信号：价格收盘在上轨之上可能意味着强势突破（趋势行情的开始），同时也可能是超买信号。区分两者的关键在于成交量（突破时放量确认）和后续K线（第二天是否继续在上轨之上）。

- 回归中轨：当价格从布林带外回到带内时，"橡胶带效应"倾向于将价格拉回中轨。在上轨附近卖出（期待回归中轨）和在上升趋势中等待回调至中轨买入，是布林带的两种经典使用方式。

- %B策略：当%B从超卖区域（如<0.1）回升至0.2以上时，作为买入信号；当%B从超买区域（如>0.9）回落至0.8以下时，作为卖出信号。

## 5.6 ATR指标（ABuNDAtr）

ATR（Average True Range，平均真实波幅）由J. Welles Wilder在1978年提出，是一种纯粹的波动率度量而非方向性指标。

### 5.6.1 数学定义

真实波幅（True Range, TR）定义为以下三者的最大值：

```
TR = max(|high - low|, |high - prev_close|, |prev_close - low|)
```

(公式5-10)

第一项是当日的价格波动范围。第二项是当日最高价超出前日收盘价的部分（涵盖了向上跳空的情况）。第三项是前日收盘价超出当日最低价的部分（涵盖了向下跳空的情况）。通过取三者最大值，TR同时捕捉了日内波动和隔夜跳空。

ATR = TR的N期移动平均。阿布量化系统的实现使用了指数加权移动平均（EWM）而非Wilder原始的SMMA。EWM使得ATR对近期波动率变化更加敏感，但牺牲了原始Wilder公式的"平缓性"。

系统默认计算ATR14和ATR21两个周期的值，分别捕捉短期（约三周）和中期（约一个月）的波动水平。

### 5.6.2 ATR的应用

ATR最主要的功能是帮助确定止损位置。常见的基于ATR的止损规则：止损位 = 入场价格 - k * ATR，其中k通常取1.5到3。例如，如果某股票入场价格为100元，ATR14=2元，k=2，则止损位为96元。

在阿布量化系统中，ATR不仅在止损策略中直接使用（ABuFactorAtrNStop和ABuFactorCloseAtrNStop），还通过ATR仓位管理（ABuAtrPosition）影响下单规模：波动率越高，每笔交易的风险敞口越小。

ATR还可以用于判断市场状态。ATR上升意味着波动率增加、市场活跃度提升、趋势可能加速；ATR下降意味着波动率减弱、市场趋于盘整。

## 5.7 其他指标

系统还实现了以下技术指标的计算框架：

### 5.7.1 KDJ随机指标

KDJ指标由George Lane在1950年代提出，通过比较收盘价在N日价格范围内的相对位置来衡量动量。其核心公式：
```
RSV = (close - low_N) / (high_N - low_N) * 100

K = (2/3) * 前K值 + (1/3) * RSV

D = (2/3) * 前D值 + (1/3) * K

J = 3 * K - 2 * D
```

(公式5-11)

### 5.7.2 CCI商品通道指数

CCI（Commodity Channel Index）由Donald Lambert在1980年提出，衡量价格与其统计均值的偏差：
```
TP = (high + low + close) / 3  （典型价格）

CCI = (TP - SMA(TP, N)) / (0.015 * mean_deviation)
```

(公式5-12)
其中0.015是Lambert的系数，使得约70-80%的CCI值落在±100之间。

### 5.7.3 Williams %R

Williams %R由Larry Williams提出，与RSI相似但使用了不同的计算方法：
```
%R = (high_N - close) / (high_N - low_N) * (-100)
```

(公式5-13)
取值范围[-100, 0]，-20以上为超买，-80以下为超卖。

### 5.7.4 ADX平均趋向指数

ADX（Average Directional Index）衡量趋势的强度（而非方向）：
```
+DM = max(high - prev_high, 0) 仅在向上运动超过向下运动时

-DM = max(prev_low - low, 0) 仅在向下运动超过向上运动时

+DI = EMA(+DM) / ATR * 100

-DI = EMA(-DM) / ATR * 100

DX = |(+DI) - (-DI)| / |(+DI) + (-DI)| * 100

ADX = EMA(DX)
```

(公式5-14)
ADX > 25通常被认为趋势较强，ADX < 20意味着市场处于无趋势/震荡状态。
